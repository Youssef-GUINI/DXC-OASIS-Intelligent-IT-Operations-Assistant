# DXC-OASIS-Intelligent-IT-Operations-Assistant
Le projet consiste à développer une plateforme intelligente d'assistance aux opérations IT basée sur l'IA agentique. L'objectif est d'aider les ingénieurs IT à gérer efficacement les incidents quotidiens, automatiser les tâches répétitives et améliorer le temps de résolution des problèmes
